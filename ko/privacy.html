← JSON 도구로 돌아가기

개인정보처리방침

최종 업데이트: 2026년 9월 12일

요약: 붙여넣은 JSON은 업로드, 저장, 저장하거나 확인하지 않습니다. JSON은 사용자 브라우저 안의 JavaScript로 파싱됩니다. 이 사이트가 수집하는 것은 아래에 정확히 설명된 Google Analytics의 익명 사용 통계뿐입니다.

1. 수집하지 않는 것

  • 입력한 JSON 또는 포맷된 출력. 이를 전달하는 요청이 없습니다. 포맷은 브라우저에서 JSON.parse를 호출하며 결과는 그대로 페이지에 기록됩니다.
  • 복사한 텍스트. 복사 버튼은 브라우저의 클립보드 API를 사용하며 로컬에서 처리됩니다.
  • 다운로드한 파일. '다운로드'는 임시 객체 URL로 브라우저 안에서 파일을 생성합니다. 서버에 도달하지 않습니다.
  • 이름, 이메일 주소, 계정, 결제 정보. 가입 절차가 없고 도구를 통해 이를 제출할 방법이 없습니다.
  • 광고 네트워크, 글꼴, 이미지, iframe이 없습니다. 유일한 타사 요청은 2절에 설명된 Google Analytics이며, 쿠키 배너에 동의한 후에만 이루어집니다. 광고 등 다른 타사 서비스를 추가하기 전에 이 방침을 업데이트합니다.

2. 수집하는 것

Google Analytics(사용 통계)

페이지는 Google Analytics 4(속성 G-S1RYL7MXPJ)용 https://www.googletagmanager.com/gtag/js를 로드합니다. 단, 쿠키 배너에 동의한 후에만 로드되며, 그 전에는 Google로 가는 요청도 쿠키 작성도 없습니다. 기록되는 것은 사이트 사용 방식이지 JSON의 내용이 아닙니다. 동의한 방문자에 대해 수집되는 데이터에는 다음이 포함됩니다:

  • 조회한 페이지, 유입 사이트, IP 주소로 추정한 대략적인 국가, 브라우저, OS, 화면 특성.
  • 카테고리와 컨트롤 이름만 담긴 상호작용 이벤트. 이 사이트가 보내는 전체 이벤트 목록: format_click, minify_click, copy_result, copy_result_floating, download_result, clear_click, example_used, indent_change(선택한 들여쓰기 너비 포함), sort_toggle(정렬 켜짐/꺼짐 여부 포함).

Google은 Analytics 4가 전체 IP 주소를 기록하거나 저장하지 않고 대략적인 위치 추정에만 사용한다고 밝히고 있습니다. 이 사이트는 JSON, 페이지 콘텐츠, 사용자 지정 식별자를 Analytics로 보내지 않습니다.

호스팅 및 전송 로그

사이트는 Vercel의 콘텐츠 전송 네트워크를 통해 제공됩니다. 다른 웹 호스트와 마찬가지로 보안과 운영을 위해 표준 요청 메타데이터(요청 URL, 타임스탬프, HTTP 상태, 사용자 에이전트, IP 주소)를 기록합니다. 사이트 소유자는 방문자별 로그를 받지 않습니다.

브라우저에 저장되는 것

두 개의 키가 저장됩니다. json-tool-theme는 dark 또는 light를 담아 테마 선택을 기억하고, cookie-consent는 배너 선택(accepted 또는 rejected)을 담습니다. 둘 다 페이지 자체가 읽고 쓰며 기기를 벗어나지 않고, 사이트 데이터를 지우면 제거됩니다.

3. 쿠키

이 사이트는 자체 쿠키를 설정하지 않습니다. 배너에 동의한 후에만 로드되는 Google Analytics가 다음을 설정합니다:

이름목적기간
_ga 무작위로 생성된 식별자를 할당하여 고유 방문자를 구분합니다. 2년
_ga_S1RYL7MXPJ 현재 세션의 분석 상태를 유지합니다. 2년

4. 법적 근거(EEA 및 영국 사용자용)

분석은 도구의 어느 부분이 사용되는지 이해하려는 정당한 이익을 근거로 처리됩니다. 원한다면 googletagmanager.com을 차단하거나 Google의 Analytics 선택 해제 브라우저 추가 기능을 사용하거나, 페이지를 로드한 후 네트워크를 꺼도 됩니다. 도구는 연결 없이도 계속 작동합니다.

5. 공유 및 판매

개인 데이터는 판매되거나 임대되지 않습니다. 데이터는 위에 언급된 서비스 제공업체(분석의 Google, 전송의 Vercel)가 각자의 약관에 따라 처리할 수 있으며, 법적으로 요구되면 공개될 수 있습니다.

6. 보관

이 사이트는 식별 가능한 어떤 것도 보관하지 않습니다. 분석 데이터는 Google Analytics 속성에 설정된 보관 설정에 따라 보관되며 해당 기간이 끝나면 Google이 삭제합니다.

7. 아동

이 도구는 일반 목적의 개발자 유틸리티이며 16세 미만 아동을 대상으로 하지 않습니다. 아동 데이터를 의도적으로 수집하지 않습니다.

8. 이 방침의 변경

페이지가 추가로 무엇인가를 수집하기 시작하면, 이 방침은 해당 변경이 적용되기 전에 업데이트되고 페이지 상단의 날짜도 수정됩니다. 업데이트 후에도 계속 사용하면 개정된 방침이 적용됩니다.

← JSON 도구로 돌아가기

소개

최종 업데이트: 2026년 9월 12일

JSON Tool은 JSON을 포맷, 미니파이, 검증하는 무료 단일 페이지 유틸리티입니다. 한 명의 개발자가 운영하는 독립 프로젝트이며, 도구 전체가 HTML 파일 하나로 구성되어 있고 자체 백엔드가 없습니다.

하는 일

  • 포맷 — 선택한 들여쓰기 너비(1~20)로 JSON을 보기 좋게 출력합니다.
  • 미니파이 — 모든 공백을 제거하여 페이로드를 줄입니다.
  • 검증 — 입력이 유효한 JSON이 아닐 때 정확한 파서 오류를 보고합니다.
  • 키 정렬 — 배열 안에 중첩된 객체를 포함해 재귀적으로 수행되므로 두 페이로드를 줄 단위로 비교할 수 있습니다.
  • 편안하게 읽기 — 줄 번호, 문자 수, 라이트/다크 테마, 클립보드 복사, formatted.json 다운로드.

대상 사용자

API 응답을 살펴보는 개발자, JSON 내보내기를 확인하는 분석가, 잘못된 페이로드를 디버깅하는 모든 사람. JSON이 무엇인지 전혀 모르는 사람도 쓸 수 있습니다. 붙여넣고 포맷을 누른 다음 결과를 읽으면 됩니다.

설계의 최우선 순위는 민감한 페이로드를 내 기기에 보관하는 것입니다. 설정 덤프, 토큰, 고객 기록, 내부 API 응답은 정확히 다른 곳에 업로드해서 다시 포맷하면 안 되는 것들입니다. 그래서 이 도구는 업로드하지 않습니다.

작동 방식

포맷은 브라우저에서 JavaScript 엔진 자체의 JSON 파서를 사용해 이루어집니다. 브라우저가 JSON을 읽을 때 사용하는 것과 같은 코드 경로입니다. 처리를 위해 서버로 전송되는 것은 없으며, 붙여넣은 내용의 대기열, 저장, 로그도 없습니다. 페이지가 로드된 후에는 네트워크를 끊고 계속 작업할 수 있습니다.

의도적으로 하지 않는 일

  • 계정 없음, 로그인 없음, 사용 제한 없음, 유료화 없음.
  • JSON에 대한 서버 측 처리 없음, 입력한 내용을 복구할 방법 없음.

알려진 제한 사항

엄격한 JSON만 허용합니다. 주석, 후행 쉼표, 작은따옴표, JSON5, JSONC, 줄바꿈 구분 JSON(NDJSON)은 거부됩니다. 이는 JSON 파서의 동작이며 버그가 아닙니다. YAML이나 XML 변환, 트리 보기는 없습니다. 다른 도구들은 망라적이기보다 의도적으로 좁게 잡았습니다. diff는 배열 항목을 위치로 맞추며 패치를 만들지 않고, 스키마 검증기는 대부분의 스키마가 실제로 쓰는 키워드를 다루며 전체 명세는 아닙니다. 각 도구 페이지가 자신의 한계를 밝힙니다.

모든 것이 탭 안에서 실행되므로 매우 큰 입력은 브라우저 메모리에 제한됩니다. 포매터는 수백 킬로바이트를 넘는 문서를 worker로 넘기고 공개한 상한을 넘으면 거부하지만, 수 메가바이트 붙여넣기는 여전히 브라우저가 직접 배치해야 하며, 그 비용은 이 사이트가 아니라 브라우저의 것입니다.

비용

무료이며 유료 요금제가 없습니다. 무엇을 수집하고 수집하지 않는지는 개인정보처리방침에 자세히 설명되어 있습니다.

소스 코드

사이트 전체——모든 페이지, 스타일, 스크립트——는 빌드 단계 없는 HTML과 JavaScript이며 MIT 라이선스의 오픈 소스입니다: GitHub의 json-tool 저장소. 값 서식의 버그나 어색한 번역을 발견하면, 그곳의 이슈는 이메일만큼 유용합니다.

직접 확인하기

확인은 세 가지, 1분이면 됩니다. 소스를 공개한 이유는 정책 문서의 약속이 아니라 확인 가능한 사실로 만들기 위해서입니다.

  • 코드를 읽으세요. 서비스되는 모든 파일이 저장소에 있습니다. 번들러도 외부 의존성도 없으므로 감사하는 파일이 그대로 실행됩니다.
  • 네트워크를 보세요. 브라우저 개발자 도구를 열고 네트워크 탭을 보면서 문서를 붙여넣으세요. 아무것도 그것을 운반하지 않습니다. 서식 정리는 브라우저 자체의 JSON.parse 호출입니다. 사이트가 하는 유일한 제3자 요청은 Google Analytics이며, 쿠키 배너에 동의한 뒤에만 발생합니다.
  • 연결을 끊으세요. 도구 페이지를 불러온 뒤 네트워크를 끊어도 됩니다. 필요한 것이 서버에 없으므로 계속 동작합니다.

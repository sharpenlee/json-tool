JSON Tool 是一款免费的轻量级页面工具，可以对 JSON 进行格式化、压缩和校验。它是由一位开发者维护的独立项目，整个工具就是一个 HTML 文件，没有自己的后端。

它的功能

  • 格式化 — 以您选择的 1 到 20 缩进宽度美化 JSON。
  • 压缩 — 去除所有空白以缩小数据体积。
  • 校验 — 当输入不是有效 JSON 时，报告准确的解析错误。
  • 键排序 — 递归进行，包括数组内嵌套的对象，方便两个数据逐行对比。
  • 舒适阅读 — 行号、字符计数、浅色和深色主题、复制到剪贴板，以及下载为 formatted.json。

为谁而做

检查 API 响应的开发者、检查 JSON 导出数据的分析师，以及所有调试异常数据的人。即使完全不了解 JSON 也能使用：粘贴、按下格式化、阅读结果。

设计上的首要原则是让敏感数据留在您的设备上。配置文件导出、令牌、客户记录和内部 API 响应，恰恰是不应该粘贴到会上传数据再重新格式化的网站上的内容。所以本工具不会上传。

工作原理

格式化在您的浏览器中通过 JavaScript 引擎自带的 JSON 解析器完成，也就是您的浏览器读取 JSON 时使用的同一套代码路径。没有任何内容被发送到服务器处理，也不存在您所粘贴内容的队列、存储或日志。页面加载完成后，您可以断开网络继续使用。

它刻意不做的事情

  • 没有账户、没有登录、没有使用限制，也没有付费墙。
  • 不对您的 JSON 进行任何服务器端处理，也无法恢复您输入的任何内容。

已知限制

它只接受严格的 JSON。注释、尾随逗号、单引号、JSON5、JSONC 以及换行分隔的 JSON（NDJSON）都会被拒绝，这是 JSON 解析器的行为，并非缺陷。没有与 YAML 或 XML 之间的转换，也没有树形视图。其他工具刻意做成小而专注，而不是大而全：diff 按位置匹配数组元素，不生成补丁；Schema 校验器覆盖大多数 Schema 实际使用的关键字，而非整个规范。每个工具页都各自说明了自己的限制。

由于一切都在你的标签页中运行，超大输入受浏览器内存限制。格式化工具会把超过几百 KB 的文档交给 worker，并拒绝超过所标上限的内容，但几 MB 的粘贴仍需由浏览器自身排版——那是浏览器的开销，不是本站的。

费用

源代码

整个站点——每个页面、样式和脚本——都是无需构建步骤的 HTML 与 JavaScript，并以 MIT 许可证开源：GitHub 上的 json-tool 仓库。如果你发现某个值的格式化有误，或某处翻译读起来别扭，在那里提交 issue 和发邮件一样有用。

自己验证

三项检查大约一分钟，这正是源码公开而非只写在政策文件里的原因：

  • 读代码。所有对外提供的文件都在仓库里。没有打包器，也没有第三方依赖，所以你审阅的文件就是运行的文件。
  • 看网络。打开浏览器开发者工具，保持“网络”面板可见，然后粘贴一份文档。没有任何请求承载它：格式化只是调用浏览器自身的 JSON.parse。本站唯一的第三方请求是 Google Analytics，而且只在你接受 Cookie 横幅之后。
  • 拔掉网线。打开一个工具页，然后断开网络。它依然可用，因为它需要的一切都不在服务器上。

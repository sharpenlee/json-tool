Última atualização: 12 de setembro de 2026

Usar o JSON Tool significa aceitar estes termos. Eles foram escritos de forma curta o suficiente para serem lidos.

1. O serviço

O JSON Tool é um utilitário gratuito baseado no navegador para formatar, minimizar e validar JSON. Não é necessária conta e nenhuma taxa é cobrada. O site pode ser alterado, ter funções limitadas ou sair do ar a qualquer momento, sem aviso prévio.

2. Fornecido «como está», sem garantia

A ferramenta é fornecida como está e como disponível, sem garantia de qualquer tipo, expressa ou implícita, incluindo adequação a um fim específico e não violação de direitos. A validação usa o parser JSON integrado do seu navegador; é esse parser que define o que conta como JSON válido, e seu comportamento pode variar um pouco entre mecanismos e versões.

3. Verifique o que importa

Não trate a saída como autoritativa para sistemas críticos. Se uma carga controla um pagamento, uma migração, um deploy ou um documento legal, verifique-a de forma independente antes de usá-la. A ordenação de chaves reordena deliberadamente os campos, o que muda a representação byte por byte mesmo que os dados sejam equivalentes.

4. Seus dados e sua responsabilidade

Você mantém todos os direitos sobre o conteúdo que cola. Como nada é enviado, o dono do site não pode acessar, fazer backup, recuperar ou auditar sua entrada — e não pode ajudá-lo a recuperar trabalho perdido na caixa de entrada. Não cole conteúdo que você não tem permissão de processar com uma ferramenta web e certifique-se de que o uso está em conformidade com as políticas de seu empregador ou cliente.

5. Uso aceitável

Não use o site para distribuir malware, para sondar ou degradar o serviço para outros usuários, nem para apresentar a saída como endosso. Não é permitido fazer scraping automatizado do site.

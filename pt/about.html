Sobre

Última atualização: 12 de setembro de 2026

O JSON Tool é um utilitário gratuito de página única que formata, minimiza e valida JSON. É um projeto independente mantido por um único desenvolvedor, e toda a ferramenta é um arquivo HTML sem backend próprio.

O que ele faz

  • Formatar — embeleza o JSON com uma largura de recuo que você escolhe entre 1 e 20.
  • Minimizar — remove todos os espaços em branco para reduzir o tamanho dos dados.
  • Validar — informa o erro exato do parser quando a entrada não é um JSON válido.
  • Ordenar chaves — de forma recursiva, incluindo objetos aninhados dentro de arrays, para que duas cargas de dados possam ser comparadas linha por linha.
  • Ler com conforto — números de linha, contadores de caracteres, tema claro e escuro, copiar para a área de transferência e baixar como formatted.json.

Para quem é

Desenvolvedores analisando uma resposta de API, analistas inspecionando uma exportação JSON, qualquer pessoa depurando uma carga malformada. Também serve para quem não faz ideia do que é JSON: cole, pressione Formatar e leia o resultado.

A prioridade de design é que dados sensíveis permaneçam na sua máquina. Dumps de configuração, tokens, registros de clientes e respostas internas de API são exatamente o que não se deve colar em um site que os envia para algum lugar reformatar. Este aqui não envia.

Como funciona

A formatação ocorre no seu navegador usando o parser JSON do próprio motor JavaScript — o mesmo caminho de código que seu navegador usa para ler JSON. Nada é enviado a um servidor para processamento, e não há fila, armazenamento ou registro do que você cola. Depois que a página carrega, você pode desconectar da rede e continuar trabalhando.

O que ele propositalmente não faz

  • Sem conta, sem login, sem limites de uso e sem paywall.
  • Sem processamento do seu JSON no servidor e sem possibilidade de recuperar qualquer coisa que você digitou.

Limitações conhecidas

Ele aceita apenas JSON estrito. Comentários, vírgulas finais, aspas simples, JSON5, JSONC e JSON delimitado por linhas (NDJSON) são rejeitados — isso é o comportamento do parser de JSON, não um bug. Não há validação de JSON Schema, nem consulta JSONPath, nem visualização de diffs, nem conversão de/para YAML, XML ou CSV.

Como tudo roda na sua aba, entradas muito grandes ficam limitadas pela memória do navegador e podem deixar a aba sem resposta. Divida arquivos com mais de alguns megabytes em vez de colá-los inteiros.

Custo

Grátis, sem plano pago. O que é e o que não é coletado está descrito por completo na política de privacidade.

Encontrou algo errado ou quer adicionar uma funcionalidade? Entre em contato — relatos de bugs com a entrada e o nome do seu navegador são os mais úteis.

JSON Tool 是一款免費的輕量級單一頁面工具，可以對 JSON 進行格式化、壓縮和驗證。它是由一位開發者維護的獨立專案，整個工具就是一個 HTML 檔案，沒有自己的後端。

它的功能

  • 格式化 — 以您選擇的 1 到 20 縮排寬度美化 JSON。
  • 壓縮 — 移除所有空白以縮小資料體積。
  • 驗證 — 當輸入不是有效 JSON 時，報告準確的解析錯誤。
  • 鍵排序 — 遞迴進行，包括陣列內巢狀的物件，方便兩個資料逐行比對。
  • 舒適閱讀 — 行號、字元計數、淺色和深色主題、複製到剪貼簿，以及下載為 formatted.json。

為誰而做

檢查 API 回應的開發者、檢查 JSON 匯出資料的分析師，以及所有除錯異常資料的人。即使完全不了解 JSON 也能使用：貼上、按下格式化、閱讀結果。

設計上的首要原則是讓敏感資料留在您的裝置上。組態匯出、權杖、客戶記錄和內部 API 回應，恰恰是不應該貼上到會上傳資料再重新格式化的網站上的內容。所以本工具不會上傳。

運作原理

格式化在您的瀏覽器中透過 JavaScript 引擎內建的 JSON 解析器完成，也就是您的瀏覽器讀取 JSON 時使用的同一套程式碼路徑。沒有內容被送到伺服器處理，也不存在您所貼上內容的佇列、儲存或日誌。頁面載入完成後，您可以中斷網路繼續使用。

它刻意不做的事情

  • 沒有帳戶、沒有登入、沒有使用限制，也沒有付費牆。
  • 不對您的 JSON 進行任何伺服器端處理，也無法復原您輸入的任何內容。

已知限制

它只接受嚴格的 JSON。註解、尾端逗號、單引號、JSON5、JSONC 以及換行分隔的 JSON（NDJSON）都會被拒絕，這是 JSON 解析器的行為，並非缺陷。沒有與 YAML 或 XML 之間的轉換，也沒有樹狀檢視。其他工具刻意做成小而專注，而不是大而全：diff 依位置比對陣列元素，不產生修補檔；Schema 驗證器涵蓋大多數 Schema 實際使用的關鍵字，而非整個規範。每個工具頁都各自說明了它的限制。

由於一切都在你的分頁中執行，超大輸入受瀏覽器記憶體限制。格式化工具會把超過幾百 KB 的文件交給 worker，並拒絕超過所標上限的內容，但幾 MB 的貼上仍需由瀏覽器本身排版——那是瀏覽器的成本，不是本站的。

費用

免費，沒有付費層級。收集什麼、不收集什麼，詳見隱私權政策。

原始碼

整個站點——每個頁面、樣式與指令碼——都是無需建置步驟的 HTML 與 JavaScript，並以 MIT 授權條款開源：GitHub 上的 json-tool 儲存庫。如果你發現某個值的格式化有誤，或某處翻譯讀起來彆扭，在那裡提交 issue 和寄信一樣有用。

自己驗證

三項檢查大約一分鐘，這正是原始碼公開、而非只寫在政策文件裡的原因：

  • 讀程式碼。所有對外提供的檔案都在儲存庫裡。沒有打包器，也沒有第三方相依，所以你審閱的檔案就是執行的檔案。
  • 看網路。開啟瀏覽器開發者工具，保持「網路」面板可見，然後貼上一份文件。沒有任何請求承載它：格式化只是呼叫瀏覽器自身的 JSON.parse。本站唯一的第三方請求是 Google Analytics，而且只在你接受 Cookie 橫幅之後。
  • 拔掉網路線。開啟一個工具頁，然後中斷網路。它依然可用，因為它需要的一切都不在伺服器上。

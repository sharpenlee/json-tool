À propos

Dernière mise à jour : 12 septembre 2026

JSON Tool est un utilitaire gratuit d'une seule page qui formate, minifie et valide du JSON. C'est un projet indépendant maintenu par un seul développeur, et tout l'outil est un fichier HTML sans backend propre.

Ce qu'il fait

  • Formater — met en forme le JSON avec une largeur d'indentation que vous choisissez de 1 à 20.
  • Minifier — supprime tous les espaces pour réduire la taille des données.
  • Valider — signale l'erreur exacte de l'analyseur lorsque la saisie n'est pas un JSON valide.
  • Trier les clés — de manière récursive, y compris les objets imbriqués dans les tableaux, afin de pouvoir comparer deux charges de données ligne par ligne.
  • Lire confortablement — numéros de ligne, compteurs de caractères, thème clair et sombre, copie dans le presse-papiers et téléchargement au format formatted.json.

À qui il s'adresse

Aux développeurs qui examinent une réponse d'API, aux analystes qui inspectent une exportation JSON, à toute personne qui débogue une charge malformée. Il est aussi utilisable quand vous n'avez aucune idée de ce qu'est le JSON : collez, appuyez sur Formater, lisez le résultat.

La priorité de conception est que les données sensibles restent sur votre machine. Les dumps de configuration, les jetons, les données clients et les réponses d'API internes sont exactement ce qu'il ne faut pas coller dans un site qui les envoie quelque part pour les reformater. Celui-ci ne le fait pas.

Comment ça fonctionne

La mise en forme s'effectue dans votre navigateur à l'aide de l'analyseur JSON du moteur JavaScript lui-même — le même chemin de code que votre navigateur utilise pour lire le JSON. Rien n'est envoyé à un serveur pour traitement, et il n'y a ni file d'attente, ni stockage, ni journal de ce que vous collez. Une fois la page chargée, vous pouvez vous déconnecter du réseau et continuer à travailler.

Ce qu'il ne fait volontairement pas

  • Pas de compte, pas de connexion, pas de limites d'utilisation et pas de paywall.
  • Aucun traitement de votre JSON côté serveur et aucune possibilité de récupérer ce que vous avez saisi.

Limites connues

Il n'accepte que du JSON strict. Les commentaires, les virgules finales, les guillemets simples, JSON5, JSONC et le JSON délimité par des retours à la ligne (NDJSON) sont rejetés — c'est le comportement de l'analyseur JSON, pas un bug. Il n'y a pas de validation JSON Schema, pas de requête JSONPath, pas de vue des différences et pas de conversion vers/depuis YAML, XML ou CSV.

Comme tout s'exécute dans votre onglet, les saisies très volumineuses sont limitées par la mémoire du navigateur et peuvent rendre l'onglet lent. Découpez les fichiers de plus de quelques mégaoctets plutôt que de les coller entiers.

Coût

Gratuit, sans offre payante. Ce qui est collecté et ce qui ne l'est pas est décrit en détail dans la politique de confidentialité.
